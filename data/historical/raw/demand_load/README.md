# Demand / Load Sources

This folder contains load-only source files.

- `powerdemand_5min_2021_to_2024_load_only.csv`: historical base demand after stripping weather columns
- `load_sldc_2021-01-01_to_2026-04-06.csv`: SLDC load series

These files are the raw inputs for the load series only. Weather must be joined separately.
